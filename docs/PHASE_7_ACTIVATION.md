# Phase 7 activation

Open [Activation](http://127.0.0.1:8000/activation) in the installed workspace.

1. **Verify resume evidence.** Use the profile review link to see drafts from the existing originals. Read the exact excerpt for each accurate career fact, select it, then review and confirm the batch. The server rejects a changed selection atomically. Old verified facts and both original snapshots were retained. If your evidence is absent, import one PDF, TXT or TEX file. An identical upload reuses the existing snapshot.
2. **Save preferences.** Enter your actual roles and locations, or explicitly allow remote work with no location restriction. Software role suggestions populate a draft that you control. Save the form to apply it. Use the existing advanced Profile editor for salary, graduation evidence, experience limits, companies and exclusions.
3. **Choose employer boards.** The ranked directory suggests candidates from saved preferences. Inspect the verified publisher and preview. Select the boards that suit you, then enable the verified selection together. Provider and employer identity are checked against the employer's careers link and the ATS board path. A fresh proof is required to enable a new board. Live checks are bounded and use the existing public feeds. Five boards are a validation target, not a requirement to proceed.
4. **Run the first real preparation.** After the checklist is complete, click **Run first real preparation**. The worker uses only the verified enabled boards captured at admission. It reserves at most five qualifying distinct jobs, including across a retry. Missing preferences, a lost verification, or active real submission settings block the run. Review outcomes from Activation, Automation or the Approval Queue.
