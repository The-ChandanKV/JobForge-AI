# Personal activation

Open [Activation](http://127.0.0.1:8000/activation) in the installed workspace.

1. Review the grouped facts and their source excerpts. Select accurate career evidence from the saved originals. The screen highlights conflicting values and preserves previously verified facts. Use Profile to manage contact details and originals.
2. Accept or edit the draft roles, locations, employment types, and experience limit. Select Remote if you want remote discovery. The draft leaves salary, relocation, graduation eligibility, and work authorization decisions in Profile.
3. Select the employer boards you want to monitor. The screen uses saved public previews and source health to rank boards. Older samples may lack posting dates and experience requirements. A preview with no suitable samples can still contain relevant jobs elsewhere in the feed.
4. Click **Confirm activation and queue first run**. JobForge saves the selections and queues one dry-run preparation in the same transaction. The worker checks fresh listings from the selected, verified boards and reserves up to five qualifying jobs. Open the Approval Queue when the worker finishes.

The hourly Windows worker operates independently of the browser. It uses the saved preferences and enabled boards after activation. The operating mode is **Autonomous preparation + manual final approval**. [Preparation workflow](REAL_APPLICATION_PREPARATION.md)
