# Intelligent job discovery

Open **Settings → Discover employers** and filter the vetted directory by company, industry, location, or role. The tags describe the directory entry. Verify source and preview jobs checks the current public feed. Enable monitoring only after verification. A newly enabled directory board needs a successful verification in the previous seven days. Priority affects queue order. Excluding a company disables its directory board and adds it to the profile exclusions.

| Source | Operations and fields | Authentication and limits | Restrictions and verification |
| --- | --- | --- | --- |
| Greenhouse | Public board list, title, location, posting and description, job identifiers | No key for listed public jobs. JobForge spaces requests by 0.5 seconds per process. | Our existing employer-authorized adapter is separate from discovery. |
| Lever | Public company postings, screening-independent description sections, title, location, commitment, official apply link | Public list uses no credential. JobForge spaces reads by 0.5 seconds. | Manual handoff. Employer-specific questions depend on the hosted application. |
| Ashby | Public published jobs, workplace type, employer-supplied dates, optional compensation | Public posting list uses no credential. JobForge spaces reads by 0.5 seconds. | Manual handoff. Unlisted postings are excluded. |
| SmartRecruiters | Public search plus full posting detail. Records public identity, location, type, and dates supplied by the endpoint. | Verified without credentials on Bosch Group. JobForge spaces requests by 0.75 seconds and reads at most 12 details per board per run. | Requests use the fixed provider origin and posting ID. Details must say public, active, and match the board. Filtered or capped snapshots cannot be used to expire otherwise absent jobs. Manual handoff. |
| Recruitee | Employer-published XML titles, descriptions, requirements, work modes, and official offer links | Public XML on The Codest required no credential. JobForge spaces requests by one second. | XML rejects DTDs and entities. We do not use the separate credentialed Careers API. Some tenants disable feeds. Manual handoff. |

A read has a size limit and bounded timeout. JobForge retries one eligible transient error and respects a longer provider backoff by deferring the source to another run. Reads do not follow redirects or collect protected forms. The latest run records provider, time, listing count and complete, partial or error status. Complete snapshots can retire absent source aliases. Partial snapshots cannot. The workspace retains source aliases and original listing timestamps while deduplicating matching content across providers. Existing descriptions are not rescored on unchanged fetches.

The live read-only adapter check returned 12 public Bosch listings and 12 The Codest listings. The Bosch search was partial by design. The Codest feed was complete. No employer board was enabled in the installed workspace. Public discoverability does not grant permission to redistribute job descriptions. The implementation accesses employer feeds directly and adds no scraping dependency. [SmartRecruiters Posting API](https://developers.smartrecruiters.com/docs/posting-api) · [Rate limits](https://developers.smartrecruiters.com/docs/rate-limiting) · [Bosch careers confirmation](https://www.bosch.com/careers/faq/) · [Recruitee feed formats](https://support.recruitee.com/en/articles/8213076-faq-api) · [The Codest careers](https://thecodest.recruitee.com/)

Employer RSS and schema.org JobPosting data can be useful when an employer explicitly publishes and permits access. Generic crawling, undocumented platform endpoints, and third-party repost feeds are outside this implementation. JobSpy is an open-source scraper. Its code license does not establish permission to automate the sites it covers, so it was not added. The existing career-ops ATS router remains available for supported URL intake.
