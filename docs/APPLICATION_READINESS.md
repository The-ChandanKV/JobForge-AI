# Application readiness

**Job Intelligence** brings together the original opening, source aliases and timestamps, eligibility, requirement evidence, missing skills, relevant projects, exact resume, and user feedback. The application review drawer displays the same readiness checklist where applicable.

| Readiness | Meaning |
| --- | --- |
| READY_FOR_REVIEW | Core facts and validated PDF exist, the supported form was inspected, and the approved provider capability is available. The user still has to give exact final approval. |
| NEEDS_INFORMATION | A core fact, eligibility decision, form answer, consent item, PDF, or reconciliation record still requires attention. |
| MANUAL_HANDOFF | The user has an official link and a prepared package to review and use on the employer site. Unknown employer questions remain unknown. |
| UNSUPPORTED | JobForge could not identify a supported submission path or an official manual destination for the available package. |
| FAILED_PREPARATION | A recorded preparation or submission failure needs review. |
| ALREADY_APPLIED | A submission is already recorded or the user explicitly reported it. User feedback alone does not create submission evidence. |

The count lists checks JobForge can verify. Unknown screening and consent are displayed as unknown for manual portals. An external page opening cannot change an application to submitted. Exact-hash approval, protected provider credentials, duplicate prevention, and receipt capture remain in the existing worker. SmartRecruiters and Recruitee additions handle discovery only.

The installed profile has a verified name and email, but verified career evidence is missing. It has no configured target roles, target locations, or enabled boards. Open Profile to verify an existing career fact and set preferences, then verify and enable sources in Settings. A live Greenhouse submission still requires separate employer authorization, verified sandbox evidence, and explicit opt-in. [Submission permissions](SUBMISSION_PERMISSIONS.md)
