# Real-world readiness

Open **Profile**, import PDF, LaTeX, or UTF-8 text, and select the original upload. Extracted facts and original text appear together. Check the excerpts, correct entries, and explicitly verify the facts you want JobForge to use. Mark unsupported claims to exclude them and prioritize verified projects when relevance ties. Import detects common sections and isolated fields such as graduation year, CGPA and GitHub links. Complex layouts and scanned PDFs can require a text copy or manual correction.

The scheduled worker requires a verified name, email, and career evidence before tailoring real jobs. It can still discover and score postings. The existing profile was preserved. On this installation the career-evidence check is incomplete and zero boards are enabled. Verify career evidence and enable appropriate public employer boards in **Settings** to start real preparation. The Profile page can populate editable software-engineering role suggestions before saving.

The recommendation combines opening requirements and verified evidence. Eligibility, freshness, preference filters, and duplicate checks remain separate. Scores express relevance on a 100-point scale. Review Queue prioritizes eligible dispatch-capable reviews, and supports explicit deadlines, manual handoffs, missing information and uncertain submissions.

Open an application to preview or download the exact PDF, review the prepared contact fields and answers, and copy values into the official employer form. Save a genuine receipt reference after submission. Rejecting a job records a reason. Optional company exclusion and senior-role filtering update preferences with the same decision. Find similar roles searches available postings already collected from permitted boards and offers a refresh of configured sources.

Greenhouse's authorized API path and the synthetic browser remain supported. Lever, Ashby, and other unsupported forms stay user-controlled.
